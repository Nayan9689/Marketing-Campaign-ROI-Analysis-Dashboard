Marketing Campaign ROI Analysis Using Power BI, Python & Machine Learning
📌 Project Overview
This project analyzes multi‑channel marketing performance to understand which campaigns drive the highest ROI and how businesses can optimize their marketing spend. It combines Python, SQL, Power BI, and Machine Learning to deliver actionable insights and predictive intelligence.

🎯 Problem Statement
Marketing teams often struggle to identify which channels deliver the best returns and where budget is being wasted.
The goal of this project was to:

Measure ROI across platforms

Identify high‑performing and underperforming campaigns

Predict revenue outcomes using ML

Provide data‑driven recommendations to improve marketing efficiency

🛠️ Approach & Tools
Python (EDA + Feature Engineering)
Cleaned and prepared campaign data

Engineered KPIs: ROI, CTR, CPA, Conversion Rate

Explored channel‑wise performance patterns

SQL (Data Structuring & Querying)
Segmented campaigns by platform and spend

Identified trends in conversions and revenue

Machine Learning (Random Forest)
Predicted revenue outcomes

Classified campaigns into High‑ROI vs Low‑ROI

Achieved ~70% accuracy

Power BI (Interactive Dashboard)
Visualized ROI, CTR, CPA, and revenue trends

Highlighted top‑performing platforms

Built drill‑downs for spend optimization

🔍 Key Insights
YouTube generated the highest revenue, outperforming other platforms.

Overall ROI reached ~1725%, indicating strong campaign efficiency.

Optimal CTR ranges were identified for better targeting.

ML model successfully classified high‑ROI campaigns, enabling smarter budget allocation.

💼 Business Impact
This analysis helps marketing teams:

Allocate budgets to the most profitable channels

Reduce spend on low‑impact campaigns

Improve targeting using CTR and conversion patterns

Predict campaign outcomes before launch

Make faster, data‑driven decisions

📈 Outcome
The project demonstrates how combining analytics with machine learning can significantly improve marketing ROI and campaign performance. It showcases end‑to‑end data science skills — from EDA to modeling to dashboard storytelling.
